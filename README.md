# Datastraw Support CRM - Full-Stack Application

A fully functional web-based customer support management system built for the Datastraw AI + Tech Intern assessment test. This system handles support tickets, real-time filtering, search functionality, priority management, and team collaboration.

---

## 🚀 Tech Stack
* **Frontend:** React, Vite, Tailwind CSS, Lucide Icons, Axios
* **Backend:** Node.js, Express.js
* **Database:** MongoDB / Mongoose (Cloud Atlas)
* **Deployment:** Vercel (Frontend) & Render (Backend)

---

## ✨ Core Features
1. **Create Tickets:** Capture customer name, email, subject, description, and priority level (`Low`, `Medium`, `High`) with auto-generated unique ticket IDs (`TKT-1001+`).
2. **Dashboard & List View:** Clean tabular view showing ticket IDs, subjects, priorities, statuses, and timestamps.
3. **Real-Time Search & Filters:** Quick search across customer names, emails, subjects, and IDs, alongside status filtering (`Open`, `In Progress`, `Closed`).
4. **Ticket Detail & Status Updates:** Comprehensive view of individual tickets with the ability to instantly update ticket statuses and priority levels.
5. **Stand-Out Feature:** Added a **Priority Level Management** system allowing support teams to triage urgent tickets efficiently.
